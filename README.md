# Persian-Sentiment-LLM-Augmentation

This repository contains the official implementation of the paper:  
**"LLM-based synthetic data augmentation for Persian sentiment classification"**
This paper is currently under review for publication.

Persian sentiment analysis faces a major challenge due to limited labeled data. Furthermore, the effectiveness of LLM‑based synthetic data augmentation for this language has not been systematically evaluated. In this study, we address this gap by using two large language models, DeepSeek‑V3‑0324 and GPT‑4o mini, to generate synthetic sentences. Three baseline Persian sentiment datasets derived from SentiPers, namely Original, Balanced, and Translation, are compared against their LLM‑augmented variants. Nine transformer models (including Persian‑specific and multilingual architectures) are fine‑tuned under a unified framework with validation‑driven hyperparameter selection for both five‑class and binary sentiment classification. A subset of generated outputs was manually inspected to confirm sentiment preservation. Results show that LLM‑augmented datasets achieve the highest test accuracy in 14 out of 18 configurations, with improvements ranging from approximately 0.3% to 2.0% depending on the model and task. These findings demonstrate that LLM‑based synthetic data augmentation consistently improves sentiment classification performance for Persian, providing a viable strategy for low‑resource NLP settings.
